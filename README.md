Welcome to the official repository for (again i'll update this trust)!

We're building a game for **Board** as part of the Generate Games Branch for the F26 semester.

## 🚀 Setup Guide

0. If you haven't done so already, [sign up for the Board Developer Program here](https://manage.kmail-lists.com/subscriptions/subscribe?a=RSttKs&g=UVV3bu) (to gain access to dev tools as well as the Discord).
1. **Install Unity:** In Unity Hub, make sure you install `Unity 6000.3.11f1`.
2. **Clone the Repo:** Clone this repository to your local machine.
3. **Yay!** You're all set!

## 📁 Project Folder Structure

Please try to keep your assets organized in the existing directory structure:

```text
Assets/
├── _Scenes/        # Levels, Menus (the _ is so it's at the top)
├── Art/            # Sprites, Textures, 3D Models, Materials
├── Audio/          # Music, SFX
├── Prefabs/        # GameObjects
├── Scripts/        # C# scripts (currently not organized BUT the idea would be that it looks like this:)
│   ├── Core/       # Managers (GameManager, AudioManager)
│   ├── Player/     # Movement, Input stuff
│   └── UI/         # Menus, HUD
└── Settings/       # Project configs and other important stuff
```
